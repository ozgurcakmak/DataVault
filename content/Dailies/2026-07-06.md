I've been tinkering again. Today I've swapped out the blog part of my website for something lighter, stranger and weirder: an Obsidian-powered knowledge garden. It syncs through GitHub and uses Quartz 5 as its "cook"

The workflow is simple in execution but probably would look insane to an outsider:

I write shit in Obsidian. When I am ready to publish I launch a terminal and go bonkers with two commands:

- `npx quartz sync` for sending it to the Webs
- `npx quartz build --serve` for testing it locally

No dashboards, no freaky JavaScript preloading, no plugin updates that bother me just because they can. Lean. Mean. And tough as houses, because it is a static site. If everything falls down, I still have my obsidian vault I can fuck off somewhere else and rebuild it in seconds. 

So why the hassle? Why did I even bother with this? Simple. Wordpress is OLD. The newer alternatives are NEW but they lack essential stuff like search and easy theming.
